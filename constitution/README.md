# Konstytucja

Tutaj trafiają trwałe, przekrojowe zasady określające, czego właściciel oczekuje od swoich komputerów. Ten katalog nie zawiera jeszcze takich decyzji.

Każdą zasadę warto umieścić w osobnym dokumencie, gdy ma niezależny temat i zastosowanie. Dokument powinien wyjaśniać intencję, zakres obowiązywania i ewentualne wyjątki. Szczegóły programu należą do `topics/`, a odstępstwa i wybory konkretnego urządzenia do jego profilu w `machines/`.

Zasady i profile powinny być ze sobą zgodne. Wyjątek należy opisać jawnie w obu powiązanych miejscach, jeśli jest istotny dla zrozumienia zasady. Nierozstrzygnięte sprzeczności wymagają decyzji właściciela.
