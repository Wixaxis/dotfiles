# Służbowy MacBook Air

## Tożsamość i rola

Jedyna maszyna służbowa właściciela: MacBook Air z macOS. Dokładny model i nazwa hosta nie zostały jeszcze ustalone.

## Zakres

Obowiązują wspólne zasady konstytucji oraz wymagania dla macOS. Ustawienia i programy przeznaczone wyłącznie dla maszyn prywatnych nie obowiązują tego laptopa. Sposób instalacji oprogramowania opisują [zasady instalacji](../../constitution/installation.md).

## Sieć prywatna

Ten komputer nie uczestniczy w planie [Tailscale i SSH dla maszyn prywatnych](../../topics/network/tailscale.md).
