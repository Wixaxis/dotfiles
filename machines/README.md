# Maszyny

Każda maszyna ma osobny katalog z plikiem `README.md`, który identyfikuje ją, opisuje jej rolę i odsyła do obowiązujących tematów oraz wyjątków. W profilu określ, czy maszyna jest prywatna czy służbowa; jeśli nie jest to ustalone, nie zgaduj. Nazwy powinny być stabilne i zrozumiałe; nie muszą ujawniać publicznego adresu ani innych wrażliwych identyfikatorów.

## Profile

- [Surface Go 2](surface-go-2/README.md) — obecna maszyna prywatna.
- [Służbowy MacBook Air](macbook-air-work/README.md) — jedyna maszyna służbowa.

Punkt wyjścia do tworzenia kolejnego profilu znajduje się w [szablonie](../templates/machine.md).
