# Aplikacje desktopowe do pracy z agentami

## Maszyny prywatne

Instaluj **T3 Code w wersji nightly**. Wybierz sposób instalacji zgodnie z [zasadami instalacji](../../constitution/installation.md), sprawdzając dostępność wersji nightly na danej platformie. Jeśli nie jest dostępna, uzgodnij dalsze postępowanie z właścicielem.

## Maszyna służbowa

Na [służbowym MacBooku Air](../../machines/macbook-air-work/README.md) instaluj **aplikację Codex na komputer**. Nie instaluj tam T3 Code nightly w ramach tej konstytucji. Codex właściciel autoryzuje samodzielnie tam, gdzie będzie to potrzebne; agent nie powinien sam rozpoczynać autoryzacji. Pozostała konfiguracja aplikacji pozostaje do ustalenia.
