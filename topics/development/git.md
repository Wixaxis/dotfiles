# Git

Na maszynach prywatnych i służbowych używaj tej samej tożsamości autora commitów Git. Konkretne imię i adres e-mail oraz pozostałe ustawienia Git nie zostały jeszcze ustalone; przed ich konfiguracją sprawdź istniejący stan i uzgodnij brakujące dane z właścicielem. Nie zakładaj wartości na podstawie nazwy konta systemowego.

Po konfiguracji sprawdź efektywną tożsamość również w kontekście repozytorium, ponieważ ustawienia lokalne mogą różnić się od globalnych. Nie zmieniaj istniejących wyjątków projektowych bez uzgodnienia.
