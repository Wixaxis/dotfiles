# GitHub CLI

## Zakres i stan docelowy

GitHub CLI (`gh`) jest wymagane na każdym komputerze. Na maszynach prywatnych i służbowej używaj tego samego konta GitHub właściciela. Podczas autoryzacji wybierz protokół HTTPS dla operacji Git z GitHub. Zainstaluj je zgodnie z [zasadami instalacji](../../constitution/installation.md) i przeprowadź autoryzację konta właściciela możliwie wcześnie, ponieważ inne etapy przygotowania mogą od niej zależeć.

Autoryzacja wymaga udziału właściciela, jeśli konieczne jest zatwierdzenie w przeglądarce. Sprawdź jej wynik bez ujawniania tokenów i kodów; nie zapisuj poświadczeń w repozytorium.
