# Tematy

Tutaj opisujemy poszczególne obszary, możliwości i programy: po co są potrzebne, jak mają działać i gdzie obowiązują. Jeden dokument lub katalog powinien obejmować jeden spójny temat; większe obszary można dzielić na dokumenty dotyczące konkretnych programów.

Nie ustalamy z góry zamkniętej listy kategorii. Tworzymy je wraz z rzeczywistą treścią, stosując zrozumiałe nazwy i odsyłacze z profili maszyn. Unikamy powielania tej samej decyzji: szczegóły opisujemy w jednym miejscu, a zakres i wyjątki wskazujemy jawnie.

Tematy nie zostały jeszcze zinwentaryzowane. Przy dodawaniu można użyć [szablonu](../templates/topic.md).
